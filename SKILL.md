# Museum Stamp Print

Turn one user photo into ONE printmaker's registration proof sheet (套版分版样张): a finished multi-block stamp print plus the step-by-step stamping diagram that builds up to it, generated with the built-in image generation tool (pass local photo paths via the `image1` parameter for image-to-image; `image2` for a second reference). Never simulate the print with code, filters, or SVG — code is used for LAYOUT ONLY (composing cells, marks).

The sheet mimics a real multi-block print's proofing record: every step cell is the previous cell plus exactly one stamped block, all at IDENTICAL size and alignment — the last cell IS the finished print.

Work autonomously through all steps; stop only if image generation is unavailable. Regenerate at most once if a quality check fails; otherwise deliver and report deviations honestly.

## Workflow

1. Inspect the source photo at full useful detail.
2. Extract: one identification anchor (the element that says WHERE/WHAT this is), the composition arrangement (keep it faithful), the light direction, and 5-6 dominant color families.
3. Decide the text content: place name (user-supplied, or the most confidently recognized location; otherwise omit) and date (today by default, format `YYYY.MM.DD`; user override wins).
4. Read [references/style-guide.md](references/style-guide.md) for the layer system, registration, and figure rules.
5. **Roll the orientation** (see Sheet layout), then shape the prompt with the skeleton below and generate. **Step sheets: use the DETERMINISTIC CHAIN ROUTE (verified — replaces whole-sheet-at-once routes, which kept violating step logic: subjects stamped steps early, blocks split across steps, same-pull colors mixed)**:
   - **Stage A — master**: generate the finished single stamp from the source photo (`image1`=photo), in the ROLLED orientation. This becomes the LAST cell.
   - **Stage B — chain one cell at a time**: cell 1 = edit the master with "show ONLY the base block — remove everything else" (`image1`=master); cell k = edit cell k-1 with "keep everything exactly as it is, stamp ONE more block: [layer]" (`image1`=cell k-1). Each prompt names the one block and restates the mixing rule (translucent mixing only against EARLIER layers; within one pull colors butt or knock out). Every cell generated in the SAME size/orientation as the master.
   - **Stage C — compose with Pillow** (printing is real generation; only layout is code): per-row-sample fill each cell's bottom-right watermark; crop each cell to its print region (explicit crop boxes after visual inspection — chained cells drift in margin size, normalize so prints read the same scale); pad to the MASTER'S aspect ratio (not always square) with each cell's own paper color; paste 2x2 on a paper-colored sheet (sheet aspect follows the master's orientation) with subtle noise; draw numerals (serif bold) outside each cell's upper-left corner and 4 sheet-corner registration crosses with PIL. No arrows.
   - Cell N (finished) = the master itself. Chain drift makes the master differ from the chained cells — fix by REVERSE CLOSING (verified): regenerate the master FROM cell N-1 ("keep the ENTIRE landscape exactly; stamp the keyline block + text"), optionally upgrading one element via a second reference image (`image1`=cell N-1, `image2`=old master — e.g. "replace ONLY the person with the better-rendered one from image 2, same spot and scale"). Then regenerate cell N-1 from the NEW master by REMOVING the keyline ("remove ONLY the near-black keyline linework and the text") — enumerate precisely which marks belong to the keyline vs earlier blocks, or the model strips earlier-block textures too (verified: wall stone-joint dashes got removed with the keyline; keep them by name).
   - **Knockout cells (verified)**: to give earlier blocks a reserved void for the foreground block — carve the void in the EARLIEST cell that needs it, using the finished master as `image2` ("remove the grey ink ONLY inside the person's silhouette; keep everything else"), then derive the OTHER early cells from that voided cell by adding/removing their own block (more reliable than voiding each cell independently — the model over-erases when asked to carve a void AND preserve surroundings; direct-void attempts wiped whole regions). **Over-erase is the top failure mode of region edits** ("remove X, keep Y"): the model rewrites Y too. Fix by a restore pass with the pre-edit version as `image2`: "restore the wall plane and road from image 2; keep the one improvement from image 1". Always diff region edits against their source before composing.
   - **Legacy whole-sheet routes (fallback only — they violate step logic; keep for their verified lessons)**: generating the single stamp with `image1`=photo traces contours far better than text alone. Whole-sheet generation with the master as `image1` tends to COPY the finished print into most cells — accumulation is unreliable and breaks at row transitions; numerals misprint near the end. Phrasings that help: "ACCUMULATION IS CRITICAL: … never show the finished scene early" with a nearly-empty cell 1, "the text appears ONLY in the last cell", negative space ("the ENTIRE UPPER HALF of cell 2 is STILL EMPTY paper"). Even the simplified 4-step 2x2 still merges adjacent low-contrast steps. TEXT-ONLY whole-sheet accumulates more reliably but traces contours loosely, and with `image1`=photo some cells render photographically.
6. Watermark-check BOTH stages (bottom-right corner): image platforms often stamp a faint watermark there. If it shares the bottom band with numerals/marks that must survive, ERASE it by filling the watermark rectangle with paper color plus slight noise (Python/Pillow) instead of cropping; otherwise crop. **Fill-color lesson (verified)**: never sample paper color from a distant corner — sample PER-ROW from the pixels immediately LEFT of the fill region and use their median; a single global sample leaves a visibly mismatched rectangular patch. Save under a clean filename and delete the watermarked original.
7. Quality-check the sheet (see below). Regenerate once if needed.

## Sheet layout (the core)

- Canvas ORIENTATION — all three supported: square, portrait, landscape. **Default is a RANDOM roll per run: 70% square (`1024x1024`), 30% non-square** (roll once at the start — e.g. `random.random() < 0.7` → square). When non-square: portrait source photo → `1024x1536`, landscape source photo → `1536x1024`; square source photo rolled non-square → pick the orientation that suits the composition. **If the user explicitly specifies square/portrait/landscape, follow the user — explicit direction always overrides the roll.** Whichever orientation is chosen, keep EVERY generation (master + all chained cells) in that same size/orientation. The 2x2 step grid stays; only the cell aspect changes. Report the rolled/chosen orientation in the delivery notes.
- **Default layout: SIMPLE 4-STEP diagram, 2x2 grid** — exactly 4 rectangles of IDENTICAL size, strict reading order, building BIG under-blocks first, small blocks last, with steps as EVENLY BALANCED as the model allows: cell 1 ONLY the largest base block(s) (bare paper field / field + road — nothing else), cell 2 = cell 1 + one big mid block, cell 3 = cell 2 + secondary masses (greenery), cell 4 = the FINISHED overprint (+ subject blocks, keyline, text). No separate finished-only cell — the last step IS the finished print. **The last step must be a BIG visible jump: +DETAILS +text, never text alone** — the anchor garment's pattern (e.g. bingata 纹样) is a separate DETAIL BLOCK stamped in the FINAL step together with the keyline and text; the garment's earlier cell shows only its plain base color. A final step that adds only text/keyline is a failure ("变化太小"). Larger layouts (1 finished + N steps, 3x2/4x2) only on explicit request — note that accumulation reliability degrades quickly beyond 4 steps.
- **Order marks**: small bold black numerals `1`, `2`, `3`… just OUTSIDE the UPPER-left corner of each cell. No gutter arrows — in a 2x2 grid the reading order is self-evident, and arrows fight with the numerals and corner crosses (verified). Numerals live only outside the print area, never clipped by the canvas edge.
- The stamp rectangle is a plain RECTANGLE (sharp corners, no rounded frame, no border, no black frame): its boundary is simply the edge of the printed color areas on the paper. Nothing draws an outline around the stamp — watch for dark bottom edging and dashed underlines beneath the text (verified remnants).
- **Step logic (hard rules)**: (a) one carved block = one step — a block's fill AND its surface texture always appear in the SAME cell, never split; (b) translucent mixing happens ONLY where a layer crosses layers from EARLIER cells — within one cell's single pull, colors butt or separate with thin white knockout gaps and never mix with each other; (c) a cell may only show mixing with layers already stamped; (d) all prints same size — the printed area reads at the same scale in every cell.
- Tiny printer's registration cross marks (套准十字线, thin hairline crosses) may sit just OUTSIDE two corners of each rectangle — they are marks, not text, and are allowed only there.
- No other text anywhere: no titles, captions, serial numbers, logos, museum names, or decorative pseudo-text.

## Text strip

- Inside the finished print near its bottom: place name in small capitals and the date, e.g. `NAHA · 2026.09.14`, set in a **vintage postal-cancellation style** (邮戳风): slightly condensed serif or stamp-engraved letterforms, unevenly inked with light patchy fade like a partially worn rubber postmark, occasional tiny ink gaps inside strokes, baseline very slightly wobbling. Still perfectly legible and misspelling-free — "worn postmark", not distressed grunge. Exact user wording overrides; omit the place name if uncertain, keep the date.

## Layer system (flexible)

- Layer count is elastic: default **4 stamping steps** (2x2 grid, see Sheet layout). More steps (up to 8) only on explicit request — and note that accumulation reliability degrades quickly beyond 4.
- **One step may carry SEVERAL colors** (one block, multi-color pull — authentic for bingata-style stencils): e.g. the anchor garment BASE block prints its plain base color in one pull; its PATTERN is a separate detail block. Note such steps explicitly in the prompt ("one block, three colors").
- Typical decomposition, back to front: background quiet field → ground/road → mid-ground masses (walls, canopy) → secondary greenery → anchor BASE color only (its pattern is NOT here) → **detail block: the anchor's pattern (bingata 纹样 etc.) + keyline + text — always the FINAL step together**, so the last transition is a big visible jump.
- Each layer is flat geometric shapes in its color family; no gradients, no photographic texture, no fine detail — structure is suggested by shape edges and sparse dashes.
- **Keyline layer** — one near-black (or darkest source color) layer containing ONLY: the text strip and the minimum possible line work (joint marks, subtle fold accents) that keeps the anchor recognizable. NO frame, NO border, NO dashed silhouette outline tracing the outer edge of a figure or object — that reads as a sticker cut line and is forbidden. Keep keyline work sparse; shapes do the talking.

**Fidelity to the source (hard rule)**: the reduction stays CLOSE to the photo — the anchor's silhouette follows the actual garment/object outline in the photo, walls/trees/ground keep the photo's positions, heights and scale, the figure keeps the photo's proportions. Simplify texture, not geometry: sheet and photo side by side must read as the same picture. In text-only mode, spend prompt words on concrete contour details (garment shape: shoulders/sleeves/hem; wall top edge; horizon height) — vague descriptions are the main cause of contour drift.

**Medium: flat ink, NOT paper cut (hard rule — verified failure mode)**: the most dangerous style drift is 剪纸/paper-craft: layered cut paper with drop shadows, visible paper thickness, felt/cardstock relief. Prevent by (a) always stating the medium positively — "flat printing ink overprinted on warm paper, like a real multi-block woodblock or rubber-stamp overprint" — and (b) an explicit NOT-list: "ABSOLUTELY NOT paper cut, NOT layered paper art, NOT collage, NOT felt craft: no drop shadows under any shape, no visible paper thickness, no physical stacking or depth between color layers, no scissors-cut cardstock edges, no 3D paper relief. Every shape lies on ONE single paper plane; overlapping inks simply darken." Mere "flat geometric shapes" is NOT enough — paper-texture vocabulary actively pulls the model toward paper collage unless the NOT-list is present. Check Stage A first: if the master drifts to paper-cut, Stage B inherits it.

**Registration**: every layer is slightly misregistered from the others (visible 1-3 mm offsets at this scale, each in its own consistent direction); where two color layers overlap by design, the ink darkens like real overprint. This misregistration is the aesthetic core — a perfectly aligned result is a failure. (The step cells show each layer's shapes at their nominal position; only the finished print shows the accumulated offsets.)

**Ink state varies per layer (the craft signature)**: the plates were pulled at different moments, so their ink differs. Give each layer its own state — one freshly inked and dense (richest, most even coverage), one or two pulled with a drier roller (streaky, mottled, bare-paper specks showing through), one medium density with a second-pull thickness, the keyline crisp but unevenly pressured (thin in places, pooling in others). Never render all layers with identical uniform density. The same ink states must carry over into the matching cells.

**Overprint is the defining trait (hard rule)**: stamp inks are slightly TRANSLUCENT, never opaque. Where a layer genuinely crosses an EARLIER layer by design (partial overlaps, e.g. foliage over a wall edge), the crossing shows a clearly DARKER MIXED tone (multiply-like: yellow over grey → olive-tinted; red over green → deep brown-red) — the overlap and non-overlap of one shape can never share the same color; mixed tones keep crisp union shapes (no soft blending, no pastel averaging). **BUT — knockout reservation for big foreground blocks (the authentic carving logic)**: a large occluding block (anchor garment/figure) is NOT overprinted onto the blocks beneath. The earlier blocks are carved with a silhouette-shaped VOID reserving its space: (a) early cells already show the blank person-shaped silhouette in the road/wall, (b) the foreground block stamps INTO the void as pure color on bare paper with hard butting edges (a thin misregistration paper-sliver along part of the silhouette is welcome), (c) NO translucent mixing between the foreground block and the layers it occludes — it reads "stamped into a reserved hole", never "pasted over, erasing what's below" (the digital-layer look). Within one pull, colors butt or knock out with thin white gaps, never mix. Inks stay flat spot colors with HARD clean edges and grainy rubber-stamp texture inside fills — no watercolor blooms, no feathered bleeds, no soft tonal edges. Shape definition comes from the keyline linework and clean edges, never from tonal softness.

## Figures (hard rules, user preferences override)

- Person seen from behind: head is a hair-color shape only (plus hat/accessories in true colors). No face at all.
- Person facing camera: face in a light neutral tone with generalized minimal features only — two short dashes for eyes, one small stroke for a mouth, drawn loosely like ink marks. Never a realistic or beautified face, never a blank void, never a black-filled silhouette.
- Clothing in true source colors. Anonymous compact silhouettes for distant people.

## Composition

- Follow the source photo's arrangement faithfully: subject positions, scale relationships, and horizon stay where the photo puts them — identical in every cell.
- Geometric abstraction with identity preserved: compress buildings, trees, and objects into decisive flat shapes while keeping the anchor recognizable at a glance.

## Prompt skeleton

> A printmaker's simple 4-step stamping diagram derived from the supplied flat block print, printed on warm off-white textured paper, [rolled orientation: 70% square, 30% non-square per the layout rule]. Medium rule: everything is FLAT PRINTING INK on paper like real woodblock overprint - ABSOLUTELY NOT paper cut, NOT layered paper collage, NOT felt craft: no drop shadows, no paper thickness, no stacking depth, no scissor-cut edges; every shape on ONE single paper plane. All four cells copy the supplied print's shapes, colors, contours and composition exactly; no photographic texture. Layout: exactly 4 rectangles of IDENTICAL size in a 2x2 grid with even paper gutters, reading order left-to-right, top-to-bottom. Each cell keeps everything from the previous cell and stamps exactly ONE additional layer, building big under-blocks first and small blocks last: CELL 1 = [large under-blocks: paper field, ground/road, big mid-ground masses]; CELL 2 = cell 1 PLUS [secondary masses]; CELL 3 = cell 2 PLUS [anchor BASE block - plain base color only, plus hair, scattered accents]; CELL 4 = the FINISHED overprint: all layers combined with slight 1-3 mm misregistration per layer, PLUS the DETAIL block (the anchor's pattern) and the near-black keyline with sparse contour dashes and the small text '[PLACE] - [DATE]' in vintage postal-cancellation capitals (patchy worn rubber postmark ink, legible). Text appears ONLY in cell 4 - no text in cells 1-3. ACCUMULATION IS CRITICAL: never skip or remove earlier layers, never show the finished scene early. ORDER MARKS: a small bold black numeral 1, 2, 3, 4 just outside the UPPER-left corner of each respective rectangle, clearly readable; NO gutter arrows. The prints are plain rectangles: NO border, NO frame, NO rounded corners, no line drawn around them, no dashed underline beneath the text; thin hairline registration crosses just outside two corners of each rectangle. Inks are slightly TRANSLUCENT spot colors with HARD clean edges and grainy rubber-stamp texture inside the fills. Every shape shows two tones: pure ink over bare paper, and a clearly darker mixed tone wherever it crosses an earlier layer (multiply-like overprint); the overlap and non-overlap of one shape can never share the same color; where shapes collide side by side, use a thin white paper knockout gap. NO watercolor blooms, NO feathered bleeds, NO soft tonal edges. [Figure rules.] No watermark, no other text anywhere.

## Quality checks

- Sheet is a strict reading-order step diagram (default: 2x2, cell 1 largest under-blocks, cell 4 finished overprint); each step = previous cell + exactly one new layer (accumulative, nothing removed); numerals present and correct; sequence unambiguous (no gutter arrows — 2x2 order is self-evident).
- All rectangles IDENTICAL size and orientation, consistent with the rolled/chosen orientation; plain prints (no frame, no border, no rounded corners); every step's shapes line up position-for-position with the finished print.
- Steps match the declared layer plan; any multi-color block is printed as one step; the FINAL step is a big visible jump (+pattern/details +text), never text alone.
- Fidelity: sheet and source photo read as the same picture (silhouettes, positions, scale).
- Text appears ONLY in the final/finished cell, worn-postmark style, correct and misspelling-free; no dashed underline under it.
- Medium is TRANSLUCENT flat ink with hard edges: no paper-cut drift AND no watercolor drift (no blooms, no feathered bleeds, no soft tonal edges); every shape shows pure ink over paper vs a clearly darker mixed tone over earlier layers — uniform color across both zones is a failure; grainy stamp texture inside fills.
- Knockout logic: the big foreground block stamps into a reserved void in earlier blocks (visible blank silhouette in early cells, pure color with hard butting edges in later cells) — never "pasted over" the layers beneath.
- No dashed outer silhouette outline around figures/objects; keyline is sparse and internal, never a sticker cut-line.
- Misregistration visible in the finished print; overprint darkening where colors overlap; ink density varies between steps.
- Registration crosses and numerals only outside the print areas; no extra text.
- Figure rules respected (no beautified face, no black silhouette).
- No watermark (check bottom-right corner; erase by paper-fill if it shares the bottom band with numerals).

## Delivery

Return the finished image. Briefly name: the identification anchor, the layer plan back-to-front, the keyline content, the ink-state variation chosen, the text strip content, the rolled/chosen orientation, and the saved path.

## Runtime notes

- Requires an image-generation tool that supports image-to-image (one or two reference images). In WorkBuddy/CodeBuddy this is `ImageGen` with `image1`/`image2`; adapt the parameter names to your environment.
- Stage C composition needs Python 3 with Pillow (`pip install Pillow`) — any local interpreter works.
- No other script dependencies; the whole flow is prompt-driven generation plus one layout script.
